# V1 Build Plan

## Milestone 1 — Vertical foundation

1. Cloudflare-compatible Next.js foundation.
2. Local D1 migrations.
3. Better Auth email/password login; public sign-up disabled.
4. One owner profile.
5. One category and one menu item.
6. Protected admin page.
7. Price update with validation and audit log.
8. R2 image upload/replacement with audit log.
9. Anonymous write denial tests.

## Milestone 2 — Public site

Home, Menu, Gallery, About, Contact, mobile Call/Menu/Directions bar, SEO, loading/error/empty states.

## Milestone 3 — Dashboard

Category and item CRUD/order, image management, featured/visible controls, gallery, settings, password flow, audit log.

## Milestone 4 — Content and QA

Import confirmed menu, process real photos, add approved temporary assets, accessibility, performance, responsive and end-to-end QA.

## Done

The owner can independently change a price and image; public changes appear; anonymous writes fail; call/maps work; mobile, performance, security, and content checks pass.
